## Как запустить турнир

Арена и все сервисы-участники работают на одной машине. Арена знает о сервисах
только их имя и порт, больше ничего ей не нужно.

### 1. Указать сервисы для арены

Сервисы передаются арене в командной строке, через пробел. Формат записи:

| Запись | Что значит |
|--------|-----------|
| `ilya=8001` | имя `ilya`, адрес `http://127.0.0.1:8001` |
| `8003` | только порт, имя будет `port-8003` |

Имена должны быть уникальными. Свой сервис добавь в этот список под своим
именем и портом. Именно тут он «регистрируется» в турнире.

### 2. Запустить арену

```powershell
cd ship-battle-arena
pip install -r requirements.txt
python -m arena ilya=8001 artem=8002 masha=8003 --games 2 --boards --report report.md
```

Арена сама сводит все пары «каждый с каждым», проводит партии, считает очки
и печатает итоговую таблицу. Побеждает тот, у кого больше очков.

| Флаг | Что делает |
|------|-----------|
| `--games N` | партий на каждую пару, по умолчанию 2 (право первого хода чередуется) |
| `--timeout S` | лимит ответа в секундах, по умолчанию 1.0 |
| `--win-points N` | очков за победу, по умолчанию 1 |
| `--seed N` | воспроизводимый прогон |
| `--verbose` | печатать каждый ход |
| `--boards` | рисовать поля обоих игроков после каждой партии |
| `--report ФАЙЛ` | сохранить итоговый отчёт в Markdown |

Быстрая проверка на двух сервисах и с подробным выводом:

```powershell
python -m arena ilya=8001 artem=8002 --games 1 --verbose --boards
```

### 3. Как читать результат

Каждая партия выводится одной строкой: кто победил и почему. Если сервис
нарушил контракт, причина указана рядом.

| Причина | Что произошло |
|---------|--------------|
| `lie` | ответ в `/opponent-shot` не совпал с реальной расстановкой |
| `timeout` / `too_slow` | сервис не ответил за 1 секунду или ответил позже |
| `connection` | сервис недоступен |
| `bad_status` | статус ответа не тот, что в контракте |
| `bad_body` | ответ не JSON или не по схеме |
| `invalid_fleet` | расстановка нарушает правила |
| `invalid_coordinate` | выстрел не в формате A1–J10 |

### 4. Частые проблемы

- **`connection: Connection refused`**: сервис не запущен или указан не тот порт.
  Проверь шаг 2.
- **`bad_status`, ожидали 201, пришло 200**: `POST /game` должен возвращать
  именно `201 Created`.
- **`too_slow`** на первом же ходу: проверь, что в адресе `127.0.0.1`, а не
  `localhost` (на Windows `localhost` может сначала уйти в IPv6 и съесть часть
  секунды).
- **Порт занят**: у другого участника тот же `APP_PORT`. Поменяйте.
